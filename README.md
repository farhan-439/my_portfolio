# Farhan Mashrur — Portfolio

Source for [mashrurfarhan.com](https://mashrurfarhan.com), built with React, TypeScript, and Vite.

## Local preview

```bash
npm ci
npm run dev
```

Open the Local URL printed by Vite. Run `npm run build` for a production check.

## Design and content

The original interactive Spline robot opens the page. Animated dots assemble into a robot face and keep pulsing until the scene is ready, then fade in place. Below it, all 12 projects appear in a compact filterable grid. Existing demo footage loops muted behind shaded title overlays while in view and resumes from the same point; Maternal has a clearly labeled animated concept preview. Pebble plays the supplied screen recording, and MedStick plays the demo from its Devpost entry. Rock–Paper–Scissors ML, SmartTrace, and Walmart Sales Workshop remain compact text-only cards. Project details expand inline without dialogs. The page includes a shorter About section, work and education logos, fully visible experience rows, research and leadership, a compact competitions section, contact with a second robot on desktop that prewarms on first load, fixed social links, and local portfolio search after the hero. Content draws on the supplied resume, LinkedIn, and public GitHub projects. Graduation is listed as May 2027. Earlier projects and campus details remain available; no personal portrait was added.

The winning hackathons appear in the competitions section and within project details, with the problem, build, and technical strengths. AvianAlert's repository reports 91.38% audio accuracy and 100% sensitivity for its unhealthy class. Private judging notes were not available.

Contact uses direct email and social links.
